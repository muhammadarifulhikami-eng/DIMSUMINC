# Dim Sum Inc. - Official Website

Website resmi dan katalog buku menu digital untuk **Dim Sum Inc.** (Signature, Bali, Plaza Festival, Kemang, dan Karawaci).

## Fitur Utama
- **Katalog Buku Menu Digital**:
  - DSI 5 Signature (12 Halaman / 6 Spread HD)
  - DSI Bali (8 Halaman / 4 Spread HD)
  - DSI Regular: Plaza Festival, Kemang, Karawaci (8 Halaman / 4 Spread HD)
  - Mode tampilan fleksibel: PC View (2 Halaman / Spread cetak) & Mobile View (1 Halaman / Vertikal)
  - Zoom & navigasi slider interaktif
- **Katalog Menu Dim Sum**:
  - 37 Pilihan Dim Sum Goreng & Kukus (*Fried & Steamed*)
  - Modal Preview Foto Hidangan resolusi tinggi
  - Informasi detail bahan, deskripsi rasa, dan sertifikasi Halal
- **5 Outlet Resmi**:
  - Plaza Festival (Jakarta Selatan)
  - Kemang Raya (Jakarta Selatan)
  - Karawaci (Tangerang, Banten)
  - Bali Island (Legian, Badung)
  - Setiabudi (Jakarta Selatan)
  - Tombol Buka Google Maps & Reservasi / Book via WhatsApp
- **Layanan & Reservasi**:
  - Formulir pemesanan meja dan layanan pelanggan terintegrasi WhatsApp (+62 811-1289-940)
- **Brand Identity**:
  - Nuansa Gelap Modern (*Industrial Vintage, Wood, Iron, Concrete, Brick*)
  - Logo Trademark Open 24 Hours

## Tech Stack
- HTML5, CSS3 Modern, Vanilla JavaScript
- FontAwesome 6, Google Fonts (Playfair Display & Plus Jakarta Sans)
